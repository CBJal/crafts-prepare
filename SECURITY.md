# Security reports

Report vulnerabilities through GitHub's [private vulnerability reporting](https://github.com/CBJal/crafts-prepare/security/advisories/new). Include the affected version or commit, impact and safe reproduction steps. Do not publish working credentials, private footage or sensitive local paths. Avoid posting an unresolved vulnerability in a public issue.

Reports should target the current default branch. This is a development project; response times and security-release dates are not guaranteed. Ordinary application bugs belong in [GitHub Issues](https://github.com/CBJal/crafts-prepare/issues).
